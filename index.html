Penceramah

Nama: Farihan Elyana Binti Zahari

Gelaran: pensyarah Politeknik Tuanku Syed Sirajjudin

Kepakaran: Mengurus pangkalan data dan penggunaan bahasa SQL untuk pembangunan sistem maklumat

Sinopsis

Ceramah ini memberi pendedahan kepada asas pangkalan data dan bahasa SQL (Structured Query Language). Peserta akan belajar konsep database, jadual (table), medan (field) dan rekod (record), serta fungsi SQL untuk memasukkan, memaparkan, mengemas kini dan memadam data. Penceramah juga akan menerangkan kepentingan database dalam sistem maklumat dan aplikasi web. Ceramah ini bertujuan membantu pelajar memahami asas SQL dan meningkatkan kemahiran pengurusan data.
